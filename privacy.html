毛线轻绕织隐私政策

更新日期及生效日期：2026年10月27日 政策版本：2.0（荣耀联运账号与退出服务版，应用版本 1.1.0） 应用包名：com.casual.maoxiangame.honor 运营者：广州瑀枫科技有限公司

重要提示

本版本具有单机毛线整理与编织换装玩法，并接入荣耀游戏联运 SDK，提供荣耀账号登录、实名认证、防沉迷、必要角色信息上报与退出服务。您需要联网完成荣耀游戏服务验证后进入游戏；本版本没有广告投放、内购或支付入口。此政策已替代旧版“无 SDK、无网络权限”的说明。

首次启动且尚未同意本政策时，我们不启动荣耀联运服务；您可先阅读本政策和用户协议。同意后再次启动应用时，荣耀联运服务可在 Application 阶段启动，完整登录初始化由您主动点击“荣耀账号登录”触发。SDK 服务可能拉起荣耀账号、游戏中心、游戏管家及其自身隐私、实名或防沉迷界面；拒绝或验证失败时不会以游客方式绕过验证。

一、我们处理的信息与目的

1. 本地游戏记录。为保存游戏进展、偏好和阅读版本，应用将当前关卡、已解锁关卡、教程完成标记、音乐与音效开关、本政策阅读版本保存在本机应用私有目录，不提供云存档。本关临时移动过程仅存在于游戏进程中，结束进程后可能重新开始当前关卡。

2. 登录标识。荣耀 SDK 登录成功后向游戏返回 Open ID 等登录结果。本游戏仅在内存中使用 Open ID 识别当前游戏会话及生成角色标识，不读取头像或昵称，不将登录令牌、Open ID 或实名证件写入普通日志或本地持久化记录，不设置独立账号注册系统。进入游戏的前提是 SDK 返回有效登录结果，并服从 SDK 的实名与防沉迷控制。

3. 必要角色上报。依荣耀联运服务要求，每次登录进入游戏及关卡发生变化时，游戏向荣耀上报角色 ID、固定角色名“编织玩家”、关卡等级、固定区服标识“local”、区服名“编织工作室”和当前章节。角色 ID 由 Open ID 的 SHA-256 摘要截取生成；它仍属于可与账号关联的标识，不因摘要处理而宣称已经匿名化。本游戏不建立自有远程账号服务器。

4. 客服。若您主动通过电话、邮件或邮寄联系我们，我们会在解决咨询、故障、投诉和个人信息权利请求所必需的范围内处理您提供的联系方式、问题描述及主动发送的材料。请勿发送无关的身份证、支付密码、验证码或其他敏感信息。客服材料不是应用自动采集或自动上传的信息。

二、荣耀联运 SDK 的信息处理

SDK 名称：荣耀游戏联运 SDK（包含荣耀账号功能），版本 2.0.28.301。 SDK 运营主体：深圳荣耀软件技术有限公司。 目的：登录、实名认证、防沉迷、游戏服务初始化、角色上报、退出挽留及账号服务更新。 处理时机：在您同意本政策后启动服务，并在主动登录、实名验证、服务更新、进入游戏、关卡变化或主动退出等相应操作时处理必要信息。

依客户提供的三方 SDK 信息收集表，荣耀 SDK 会处理账号信息（Open ID）、设备标识符（UDID）、设备信息（型号、操作系统版本、语言、ROM 版本、国家码）及应用信息（包名、版本、网络类型）；进行实名认证时，您在荣耀页面主动提交的姓名和身份证号由荣耀处理，本游戏不自行提供证件输入框，也不获取证件明文。SDK 的统计、设备标识及安全依赖可能依其声明使用相应设备标识（如 OAID）、网络与运行诊断信息，具体处理规则以荣耀当时展示的政策及授权说明为准。

荣耀 SDK 及其依赖清单：game 2.0.28.301、hianalytics-white 1.0.6.301、ads-identifier 1.0.3.300、security-encrypt 1.2.5.306、security-ssl 1.2.5.312、enc-ha 8.3.0.104，均为荣耀联运服务、运行诊断、标识与安全支持组件。ads-identifier 的存在不代表本游戏投放广告。联运 AAR 内含支付组件，但本游戏未调用购买、订单或支付接口，未设置付费商品。

AndroidX core、annotation、lifecycle、collection、versionedparcelable 为界面与系统兼容支持库，不作为本游戏独立广告、账号或云端统计服务。

三、权限及系统能力

合并安装包声明网络访问（INTERNET）、网络状态（ACCESS_NETWORK_STATE）、Wi-Fi 状态（ACCESS_WIFI_STATE）权限，用于游戏服务连接、连接状态判断和 SDK 运行诊断；这些普通权限不等于定位授权。本游戏不申请位置、通讯录、相机、麦克风、电话或短信危险权限，也不读取剪贴板。

SDK 另声明前台服务（FOREGROUND_SERVICE），用于其服务与更新流程；REQUEST_INSTALL_PACKAGES 用于必要时引导更新或安装官方荣耀账号服务，属于特殊应用安装访问能力，不会由本游戏静默安装应用。是否允许安装由您和系统安装界面决定，您可在系统设置中关闭相应特殊访问。

SDK 还声明与荣耀游戏中心、游戏管家及内置服务相关的受保护访问权限，包括 com.hihonor.gamecenter.service.provider.READ_PERMISSION、WRITE_PERMISSION、com.hihonor.gameassistant.permission.AGREE_READ_PROVIDER、AGREE_WRITE_PROVIDER 及 com.hihonor.iap.core.permission.ACCESS_PURCHASE_SERVICE。这些声明由官方联运 AAR 带入，不表示游戏启用了支付。

应用仅声明对荣耀账号、游戏中心、游戏管家、应用市场等指定包的可见性查询，以便 SDK 关联服务；不声明 QUERY_ALL_PACKAGES，不遍历完整应用安装列表。openid 是荣耀账号授权范围，不是 Android 系统危险权限；本游戏关闭昵称和头像授权请求。

四、共享、转让、公开披露与跨境

为提供上述服务，必要账号与角色信息会传递给荣耀 SDK 运营主体。请在授权前阅读本政策及荣耀自己的说明。我们不出售、出租个人信息，不将游戏数据用于独立广告画像，不接入其他商业广告或支付服务。

除本政策已说明的荣耀服务及您自愿使用的客服渠道外，不向其他主体提供个人信息；依法履行义务等法定情形除外。若发生主体变更、数据转移或新的共享场景，将依法履行告知及需要的授权程序。游戏没有自有境外服务器；荣耀相关数据地域与保存规则依其政策及您的服务区域适用规则处理，客户 SDK 表声明不向境外提供信息。

五、保存期限与保护

本地记录保存在设备应用私有目录中，关闭应用系统备份；清除数据或卸载前为本地功能持续保留。Open ID 仅在本次应用进程内用于当前会话，退出进程后释放。本游戏不持有荣耀实名证件明文。荣耀接收的账号、实名、设备、角色及诊断信息由荣耀依其政策、处理目的和法定期限管理，删除本机进度不等同于删除荣耀平台上的记录。

您主动向公司提交的客服材料在中国大陆处理，原则上保存至问题解决后六个月；法律另有要求、争议尚未结束等情形，在必要期限内保存。我们采取必要访问限制、安全管理和最小化处理措施。发生或可能发生信息安全事件时，依法采取补救和通知措施。

六、您的权利与操作路径

您可在首页和暂停菜单阅读本政策及用户协议；通过关卡目录查看本机解锁进度，通过设置调整声音。暂停菜单中的“清除本地数据 / 撤回阅读记录”经二次确认后清除进度、设置和同意记录，并退出应用及当前进程；下次使用需重新同意和登录。这不会注销您的荣耀账号，也不会自动删除荣耀保存的信息。

本游戏无独立账号注销入口。关于荣耀账号注销、实名认证资料、荣耀服务中的信息查阅、更正、删除或撤回授权，请通过荣耀账号设置及其隐私政策中的渠道办理。我们可协助您了解适用路径。因必要账号或实名服务不可用而无法进入游戏，不会改用游客身份绕过验证。

对于公司实际处理的客服材料，您可要求查阅、复制、更正、补充、删除、撤回已作出的同意，或解释处理规则。一般通过原联系渠道核实身份，不要求您为普通咨询提交身份证照片。我们在收到请求后十五个工作日内回复；不能满足的会说明理由。您可向主管机关投诉或依法寻求司法救济。
